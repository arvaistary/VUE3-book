# Поток подготовки книги

## Входы

- учебные цели и последовательность тем внутреннего курса;
- решения из канонической спецификации;
- редакционные правила и политика публичной безопасности;
- синтетические примеры кода и результаты их проверки.

## Основной поток

1. Из темы курса выделяется переносимая инженерная проблема.
2. Проблема описывается в спецификации книги без закрытых деталей.
3. Для главы готовятся объяснение, плохой пример, хороший пример и упражнение.
4. Черновик проходит техническую, редакторскую и конфиденциальную проверку.
5. Проверенный материал переносится из `draft/` в `public/`.

## Выходы

- спецификация и план work item;
- проверяемый список задач;
- черновая глава;
- чистовая глава;
- свидетельства запуска проверок.

## Ошибки и восстановление

Если пример раскрывает внутреннюю деталь, неясен читателю или не проходит
проверку, материал остаётся в `draft/` и возвращается на переработку. Нельзя
обозначать главу готовой только потому, что она написана.
