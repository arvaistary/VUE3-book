# Архитектура проекта книги

## Форма проекта

Это репозиторий документации с двумя потоками содержания: рабочим `draft/` и
публикуемым `public/`. Spec-Kit хранит решения и ход работы в `specs/`, а
workflow размещён в служебных каталогах.

## Основные части

- `draft/` — черновики, редакционные правила и контрольные материалы;
- `public/` — чистовая рукопись;
- `specs/` — канонические work items;
- `.specify/` — шаблоны, скрипты и долговременный контекст;
- `workflow/core/` — универсальные gates;
- `workflow/project/` — проверки книги и её правила.

## Границы

Внутренний курс является входным материалом, а не частью публикуемой
рукописи. Переход в `public/` допускается только после обезличивания,
редакторской проверки и проверки примеров.

## Результат

Каждая глава должна быть самостоятельной: читатель понимает проблему,
термины, плохой и хороший код, компромиссы и способ проверить результат без
доступа к закрытым системам.
