# Технологический профиль книги

## Формат

- Markdown — спецификации, рукопись и редакционные документы;
- Bash — workflow и проверки project adapter-а;
- Git — provenance, scope и чистота worktree;
- Node.js со стандартной библиотекой — точечные проверки Markdown, если они
  нужны adapter-у.

У книги нет серверного runtime, базы данных, API или пользовательского
интерфейса приложения.

## Проверки

- структурная проверка установки workflow;
- проверка публичной структуры и запрещённых внутренних ссылок;
- проверка незаполненных шаблонов и пустых глав;
- проверка shell-синтаксиса и whitespace.

## Ограничение доказательств

Эти проверки подтверждают качество рукописи и workflow. Они не являются
тестами исходного приложения и не доказывают поведение закрытого проекта.
