# Проектирование frontend-систем

Самостоятельная техническая книга о проектировании frontend-приложений:
состоянии, серверном рендеринге, границах ответственности, пользовательских
сценариях, производительности, качестве изменений и эксплуатации.

Книга написана на литературном русском языке и рассчитана на разработчиков от
начинающего до уверенного middle-уровня. Примеры синтетические и не требуют
доступа к исходному проекту.

## Ветки репозитория

- main — опубликованная версия для читателей;
- drafts — рабочие материалы, редакторские заметки и инструменты подготовки.

Новые изменения сначала проходят проверки в drafts. В main переносится только
проверенный текст и новый проверенный EPUB.
