# Публичная книга о разработке frontend-систем

Этот каталог предназначен для подготовки книги на основе внутреннего курса
лекций. Книга объясняет архитектурные решения доступным языком и использует
небольшие самостоятельные примеры кода.

## Границы проекта

- `draft/` — рабочие материалы, редакторские заметки и черновики глав;
- `public/` — вариант рукописи, подготовленный к публикации;
- `specs/` — канонические Spec-Kit work items: спецификация, план и задачи;
- `.specify/`, `.agents/`, `.codex/`, `workflow/` — установленный
  Spec-Kit Modern и его project adapter.

Внутренний курс используется как источник тем и учебных целей. Его реальные
пути, имена проекта, API-контракты, конфигурации, показатели и другие детали
не переносятся в `public/`. Примеры книги должны быть самостоятельными и не
требовать доступа к исходному проекту.

## Рабочий порядок

1. Прочитать каноническую спецификацию активного work item.
2. Уточнить план и задачи до начала написания.
3. Подготовить главу в `draft/` по редакционному шаблону.
4. Проверить кодовые примеры, ссылки, стиль и публичную безопасность.
5. Перенести только проверенный текст в `public/`.

Проверки из корня книги:

```bash
bash workflow/project/verify-workflow.sh
bash workflow/project/lint-workflow.sh
```

## Статус

В активном work item подготовлены briefs, введение и восемь глав в `draft/`,
прошедшие проверки материалы перенесены в `public/`, а задания T009–T032
отмечены выполненными. Фактические команды и evidence записаны в
`specs/001-public-book-foundation/evidence.md`; финализатор запускается после
коммита и остаётся последним gate work item-а.
