# Черновики книги

Здесь находятся рабочие материалы, которые ещё не готовы к публикации.

Каждая глава проходит путь:

1. brief и учебная цель;
2. черновой текст и примеры;
3. техническая проверка;
4. редакторская проверка;
5. проверка публичной безопасности;
6. перенос в `public/`.

Не используйте эту папку как место для хранения секретов. Секретные сведения
не нужны для написания книги и не должны появляться в рабочем дереве.
