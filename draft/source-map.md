# Карта переноса тем

Эта карта связывает внутренний курс с публичной структурой книги. Она описывает
только учебные темы и не является копией исходного проекта.

| Часть книги | Темы курса |
|-------------|------------|
| 1. Как мыслить о frontend-системе | архитектура и окружение |
| 2. Состояние приложения | state management и SSR |
| 3. Границы ответственности | API, сервисы, plugins и middleware |
| 4. Пользовательские сценарии | авторизация, формы и сложный UI |
| 5. Производительность | performance, SEO и внешние интеграции |
| 6. Качество изменений | TypeScript, тестирование и ревью |
| 7. Доставка приложения | Docker, Helm, Kubernetes и эксплуатация |
| 8. Устойчивые решения | popup-состояние и паттерны Vue |

При написании главы переносится идея и учебная цель, но не конкретная
реализация, структура каталогов или значения конфигурации.
