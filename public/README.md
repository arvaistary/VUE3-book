# Книга о разработке frontend-систем

Рукопись готовится. Публикуемый вариант будет состоять из самостоятельных
глав с доступными объяснениями, плохими и хорошими примерами кода,
ограничениями решений и упражнениями.

Текст в этой папке должен быть понятен без доступа к исходному проекту и не
должен содержать его внутренние детали.

Начать знакомство со структурой можно с [содержания](./contents.md).
