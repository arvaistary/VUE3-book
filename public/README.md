# Книга о разработке frontend-систем

Книга состоит из самостоятельных
глав с доступными объяснениями, плохими и хорошими примерами кода,
ограничениями решений и упражнениями.

Начать знакомство со структурой можно с [содержания](./contents.md).

Рекомендуемый маршрут — введение, затем части 1–8. Если вы изучаете Nuxt,
начните с части 1: она вводит Nuxt 3 и показывает безопасный план перехода к
структуре Nuxt 4. Остальные части последовательно разбирают
состояние, границы, пользовательские сценарии, производительность, качество
изменений, доставку и устойчивые UI-решения.
