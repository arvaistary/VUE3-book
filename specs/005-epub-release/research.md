# Research: выпуск книги в EPUB 3.3

## Контекст

Публичная рукопись уже прошла читательский, Nuxt-технический и runtime-аудит.
EPUB должен быть производным артефактом: он не меняет Markdown, не включает
рабочие документы и не добавляет новый текст.

## Нормативный источник

Проверено 2026-09-04: [EPUB 3.3 Recommendation](https://www.w3.org/TR/epub-33/)
и [EPUB 3.3 Overview](https://www.w3.org/TR/epub-overview-33/).

Из стандарта для этой работы используются следующие требования:

- EPUB распространяется как ZIP-контейнер;
- корневой mimetype должен идентифицировать EPUB, а container.xml указывает
  на package document;
- package document содержит metadata, manifest и spine;
- navigation document является XHTML-документом для навигации;
- content documents могут быть XHTML и должны оставаться пригодными для
  reflowable-чтения.

## Решения

### Входной manifest

В EPUB входят только:

1. public/contents.md;
2. public/00-introduction.md;
3. public/01-system-thinking.md;
4. public/02-application-state.md;
5. public/03-boundaries.md;
6. public/04-user-scenarios.md;
7. public/05-performance.md;
8. public/06-change-quality.md;
9. public/07-delivery.md;
10. public/08-resilient-patterns.md.

public/README.md является служебной страницей репозитория и исключается.

### Конвертация

Небольшой встроенный Markdown renderer покрывает синтаксис, который реально
использует рукопись: заголовки, абзацы, списки, fenced code, inline code,
emphasis, blockquotes и ссылки. Сложный Markdown-процессор не добавляется,
потому что он расширил бы поверхность зависимостей и не нужен для текущего
текста.

HTML-подобные символы в тексте и коде XML-экранируются. Внутренние ссылки
перенаправляются на XHTML-файлы EPUB, внешние HTTPS-ссылки сохраняются.

### Архив

Сборщик формирует ZIP стандартной библиотекой Node.js: mimetype записывается
первым, без сжатия; остальные entries сжимаются DEFLATE. Порядок entries,
время DOS и содержимое фиксированы, поэтому одинаковый вход даёт одинаковый
SHA-256. Это не требует npm-пакета или внешнего конвертера.

### Метаданные и доступность

Публикация будет reflowable, с языком ru, XHTML lang=ru, заголовками,
navigation document и CSS без фиксированной ширины. Обложка — текстовая
титульная XHTML-страница без непроверенных изображений и лицензий. Автор
намеренно не указывается: подтверждённое имя не передано в задаче.

## Ограничения

- Renderer не является универсальным CommonMark-процессором.
- Интерактивный JavaScript, изображения, сноски и сложные таблицы потребуют
  отдельного расширения, если появятся в рукописи.
- Checker подтверждает структуру и содержимое архива, но не заменяет
  визуальное открытие в каждой EPUB-читалке.
- Внешние ссылки не проверяются сетью: проверяется их классификация и XML
  encoding.
- Результат не подписывается, не шифруется и не содержит DRM.

## Отклонённые альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| Pandoc или npm Markdown-пакет | инструмент не установлен, а добавление зависимости не нужно для текущего синтаксиса |
| ZIP-команда как единственный сборщик | труднее гарантировать одинаковый порядок и timestamps на разных системах |
| Включить весь public/ | служебный README не является частью книги |
| Сгенерировать обложку изображением | нет подтверждённых прав и потребности в растровом asset |
| Переписать Markdown ради EPUB | нарушает границу производного формата и увеличивает риск расхождения рукописей |
