# Принципы книги

Эти правила применяются ко всем главам и не заменяют спецификацию конкретного
work item-а.

| Документ | Назначение |
|----------|------------|
| `best-practices.md` | устойчивые правила подготовки текста и примеров |
| `anti-patterns.md` | повторяющиеся ошибки автора и агента |
| `workflow-patterns.md` | порядок работы с draft и public |
| `code-review-mistakes.md` | вопросы финального ревью |
