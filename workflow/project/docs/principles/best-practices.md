# Практики книги

## Правило

Каждая глава отвечает на один понятный вопрос читателя и ведёт его от
проблемы к проверяемому решению.

## Зачем это нужно

Так текст не превращается в перечень терминов, а читатель понимает, какую
проблему решает архитектурное решение и чем за него платит.

## Рекомендуемый вариант

```text
проблема → термин → плохой пример → разбор → хороший пример → компромиссы → упражнение
```

## Проверка

В черновике должны быть явно видны цель главы, два варианта решения,
объяснение последствий и способ самостоятельной проверки.
