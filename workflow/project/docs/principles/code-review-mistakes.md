# Типичные ошибки ревью книги

| Область | Вопрос ревью |
|---------|--------------|
| Публичная граница | Не осталось ли реальных имён, путей, API, конфигурации или внутренних метрик? |
| Понятность | Понимает ли читатель проблему до того, как увидит код? |
| Термины | Объяснен ли каждый новый термин до первого примера? |
| Плохой пример | Понятно ли, почему вариант плох и какое последствие он создаёт? |
| Хороший пример | Можно ли запустить или проверить пример без закрытого проекта? |
| Компромиссы | Описаны ли границы применимости решения? |
| Ссылки | Работают ли локальные ссылки и не ведут ли они во внутренние документы? |
| Версионность | Указана ли версия технологии там, где от неё зависит пример? |
