# Workflow-паттерны книги

## Pattern: глава от проблемы к решению

- **Когда применяется:** при подготовке любой содержательной главы.
- **Разрешённый переход:** утверждённый brief → draft → review → public.
- **Запрещённый переход:** draft → public без технической и конфиденциальной проверки.
- **Какие операции учесть:** изменение текста, добавление примера, перенос главы.
- **Проверка:** `bash workflow/project/scripts/check-book.sh` и чеклист ревью.

## Pattern: источник и публичная абстракция

- **Когда применяется:** когда тема основана на закрытом проекте.
- **Разрешённый переход:** внутренняя идея → нейтральная модель → синтетический код.
- **Запрещённый переход:** внутренний путь, API или конфигурация → public.
- **Какие операции учесть:** перенос фактов и примеров.
- **Проверка:** политика `draft/confidentiality-policy.md` и проверка public boundary.
