# Технологический контекст книги

Книга является Markdown-проектом. В ней нет прикладного runtime: продуктовым
результатом считается рукопись в `public/`, а не поведение веб-приложения.

## Среда

| Область | Решение |
|---------|---------|
| Текст | Markdown в UTF-8 |
| Скрипты | Bash с `set -euo pipefail` |
| Дополнительные проверки | Node.js standard library без обязательного npm-пакета |
| Provenance | Git worktree книги |
| Публикуемый результат | `public/` |

## Ключевые пути

| Путь | Назначение |
|------|-----------|
| `draft/` | черновики и редакционные проверки |
| `public/` | чистовая рукопись |
| `specs/` | спецификации, планы и задачи work items |
| `.specify/memory/` | долговременный контекст и правила |
| `workflow/core/` | универсальный workflow |
| `workflow/project/` | проверки книги |

## Gates

`check-book.sh` проверяет наличие зон книги, отсутствие незаполненных
шаблонов и запрещённых внутренних ссылок в `public/`. `lint-workflow.sh`
проверяет shell-синтаксис и whitespace workflow-изменений.

## Bootstrap

После клонирования достаточно установить Bash, Git и Node.js, затем выполнить
проверки из README. Для написания Markdown-зависимости не нужны.
