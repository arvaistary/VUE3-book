# Шаблоны project adapter-а

В этом каталоге находятся исходные формы документов для адаптера проекта.
Рабочие документы книги находятся в `workflow/project/`, а эти файлы служат
опорой при переносе workflow в другой репозиторий.

Перед использованием замените описательные места фактами конкретного проекта
и проверьте команды через `profile-contract-test.sh`.
