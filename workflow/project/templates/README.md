# Шаблоны документов проекта

Каталог содержит заготовки для новых локальных документов и расширений
workflow. Они помогают сохранить одинаковую структуру требований, gates,
principles и technology profile.

## Как использовать

1. Скопируйте нужный файл в соответствующий каталог `workflow/project/`.
2. Замените значения в угловых скобках фактами текущего репозитория.
3. Удалите необязательные разделы, которые не относятся к задаче.
4. Проверьте команды и profile через локальные smoke-проверки.
5. Сохраните результат в документации проекта до первой задачи, которая на него
   опирается.

| Шаблон | Назначение |
|--------|------------|
| `stack.md` | технологический и runtime-контекст |
| `technology-profile.env.example` | команды и роли артефактов |
| `gates-extensions.md` | дополнительные проверки |
| `agent-dod.md` | критерии готовности |
| `technology-integrity-report.md` | отчёт о технической целостности |
| `principles/*.md` | устойчивые правила и антипаттерны |

`workflow/core/` задаёт неизменяемые общие gates. Локальные документы могут
добавлять требования, но не могут ослаблять контракт, scope, provenance или
Evidence Index.

Profile — доверенная конфигурация репозитория, а не пользовательский ввод и не
хранилище секретов.
