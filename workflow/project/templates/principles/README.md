# Принципы проекта — <название локального слоя>

Здесь находятся устойчивые правила, которые читаются перед реализацией и
ревью. Решения одной задачи остаются в её `spec.md`.

| Документ | Для кого | Когда читать |
|----------|----------|--------------|
| `best-practices.md` | агент и человек | всегда |
| `anti-patterns.md` | агент и человек | всегда |
| `workflow-patterns.md` | агент | состояния и side effects |
| `code-review-mistakes.md` | агент и reviewer | перед финализацией |

Каждое правило должно содержать формулировку, объяснение, пример, запрещённый
вариант и способ проверки. Команды и пути сверяйте с README и profile.
