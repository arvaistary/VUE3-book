## Команды проверки

```bash
# Основная проверка
<test command>

# Lint и статический анализ
<lint command>

# Дополнительный runtime, если он нужен
<runtime command>

# E2E или security-сценарий, если он нужен
<e2e-or-security command>
```

Для concurrency отдельно укажите, почему выбранный runtime даёт достоверное
доказательство. Skipped и unavailable не закрывают обязательный gate.

## Границы изменений

Опишите типичный allowlist и denylist. В denylist включите служебные файлы,
локальные артефакты, generated output, секреты и каталоги IDE. Отдельно
укажите, где хранятся spec и report.

## Воспроизводимость

Опишите запуск из чистого checkout-а: зависимости, переменные окружения,
подготовку, проверки и безопасное завершение. Команды, которые удаляют данные,
допускаются только с явным предупреждением.
